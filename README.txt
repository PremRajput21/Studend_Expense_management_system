STUDENTSPEND — STUDENT EXPENSE MANAGEMENT SYSTEM
=================================================

PAGES INCLUDED
1. index.html       Login page
2. signup.html      Create account / sign-up page
3. dashboard.html   Dashboard overview and recent transactions
4. expenses.html    Transaction list, search, filter, sort, delete
5. add-expense.html Add expense form
6. budget.html      Monthly budget and progress indicator
7. reports.html     Category report, insights, CSV export
8. profile.html     Update profile name
9. settings.html    Export data and clear expense data
10. help.html       FAQ and project help

TECHNOLOGIES
- HTML
- CSS
- JavaScript
- Browser LocalStorage (no server/database required)

HOW TO RUN
1. Extract the ZIP file into a folder.
2. Open the folder in Visual Studio Code.
3. Recommended: install the Live Server extension.
4. Right-click index.html and choose "Open with Live Server".
   Or open index.html directly in your browser.
5. Create an account on the sign-up page, then use the app.

FEATURES
- Demo login and sign-up
- Add and delete expenses
- Category selection and payment method
- Monthly budget and progress
- Search, category filter, and sorting
- Spending breakdown and insights
- Export transactions as CSV
- Profile settings
- Responsive layout for mobile and desktop

IMPORTANT LIMITATIONS
This is a front-end college project/demo. Authentication is NOT secure: passwords are stored in browser LocalStorage, and data is only on that browser/device. Do not use real passwords or sensitive data. A real-world version should use a backend API, a database, secure password hashing, and proper authentication.

If you clear browser data, the saved demo information may be lost.
